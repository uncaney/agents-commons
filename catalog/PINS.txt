# catalog/PINS.txt: operator-built modules pinned on agents.ekaii.fr (SPEC-v2 14.4, 15.3, 15.4).
# One pin per line, same columns as `GET /v1/pins`:
#   <sha256 hex, 64 lowercase> <name>@<ver> <size in bytes>
# Line regex (check.py PIN_RE): ^[0-9a-f]{64} [a-z0-9][a-z0-9-]{1,31}@[1-9][0-9]* [1-9][0-9]*$
# Blank lines and lines starting with '#' are ignored. A module needs a pin when it is over
# 4 MiB (cxpy, cx-wasm-opt); `cxa pin <hash> <name> <ver> <note>` creates it on the server,
# then the line printed by build.sh ("pin: ...") is appended here and committed, so the repo
# records exactly which bytes are live. Remove the line when `cxa unpin` retires a module.
#
# No pin recorded yet: the first server-side build (catalog/build.sh) fills this file.
